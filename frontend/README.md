# 📺 SyncParty Frontend

React 19 + Vite frontend client for the YouTube Watch Party System.

## Features
- Real-time video player synchronization using YouTube IFrame API (`react-youtube`)
- WebSocket client (`socket.io-client`)
- Role-based interface (Host, Moderator, Participant)
- Direct link prompt modal
- Real-time chat & animated emoji bursts
- Styled with modern dark theme CSS glassmorphism & Lucide icons

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
